# 🛒 Blinkit Clone

A responsive **Blinkit Clone** website created using **HTML, CSS, Bootstrap, and Font Awesome**. This project recreates the basic look and layout of a quick-commerce grocery delivery website, including a navigation header, search bar, promotional banners, product categories, and product cards.

## 📌 Project Overview

The Blinkit Clone is a frontend web development project designed to practice building a modern e-commerce interface. The website provides a clean and responsive shopping layout inspired by quick-commerce platforms.

The project includes grocery and daily-use product sections with product images, prices, delivery-time indicators, and **ADD** buttons.

## 📱 Responsive Design

The project uses CSS media queries to provide a responsive layout.

On smaller screens:

* Header changes to a vertical layout
* Product cards adjust to smaller widths
* Category images stack vertically
* Search bar adapts to the screen width
* Login and cart buttons are positioned at the bottom
* Product sections become mobile-friendly

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/your-username/blinkit-clone.git
```

### 2. Open the project

Navigate to the project folder:

```bash
cd blinkit-clone
```

### 3. Run the website

Since this is a frontend HTML/CSS project, you can simply open:

```text
index.html
```

in your browser.

You can also use **VS Code Live Server** to run the project.
